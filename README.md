# Metro Unjam 🚇

یک بازی پازل کوچک: روی هر سکو بزن تا مسافرِ اولِ صف سوار قطارِ هم‌رنگ شود، قبل از این‌که صبرش تمام شود.

A small static HTML + JS puzzle game. Tap a platform to board its front passenger onto the matching-colour train.

- Play: open `index.html` (or the GitHub Pages link)
- Levels: `levels.js`
- Keys: `1`–`4` tap platforms, `R` restart, `Esc` menu
